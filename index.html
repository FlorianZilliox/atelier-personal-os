Avant tout

Lire les fichiers .md dans Chrome

  • Extension MD RendererAffiche les fichiers .md mis en forme, directement dans Chrome..zip
  1. Décompressez le .zip, gardez le dossier md-renderer quelque part (il ne doit plus bouger).
  2. Dans Chrome, ouvrez chrome://extensions et activez le Mode développeur (en haut à droite).
  3. Charger l'extension non empaquetée, et choisissez le dossier md-renderer.
  4. Sur la carte MD Renderer : Détails, puis activez Autoriser l'accès aux URL de fichier.

Ouvrez ensuite un .md téléchargé en le glissant dans Chrome. Si votre poste bloque le mode développeur, prenez les versions .txt.

Mode d'emploi

Playground en 6 gestes

  1. Un workspace : Mes données, créer un espace, y verser les fichiers. Dans une conversation, « + » pour l'utiliser. Plusieurs workspaces à la fois, c'est possible.
  2. Un connecteur : dans les outils, Connecter, puis Autoriser, puis cocher. Pour Jira, donnez la clé de votre projet. Vos comptes rendus Seedext arrivent par mail : Outlook suffit pour les lire.
  3. Un agent : en haut à droite, créer un agent. C'est là qu'on met un workflow qui produit un livrable.
  4. Un skill, sur Playground, n'est qu'un prompt réutilisable : bien pour une demande simple et répétitive.
  5. Le modèle : mode avancé, Tera.
  6. Le quota : cochez seulement les outils utiles, une nouvelle conversation par tâche.

Si Playground refuse un fichier .md, prenez la version .txt.
