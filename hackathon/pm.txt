# Hackathon PM : un copilote de discovery

## Le problème
Appliquer SOLVE demande de la discipline : passer les étapes dans l'ordre, ne pas recopier la demande, aller chercher ce que les interviews ne disent pas encore.

## Votre agent
À partir de vos interviews, il vous guide dans SOLVE : il propose le livrable de l'étape, montre ce qui manque, et **pose les questions qui creusent**, celles d'un PM senior. Pas « quel est votre indicateur ? », mais « la dernière fois que c'est arrivé, qu'est-ce que ça vous a coûté ? ».

## Ce que vous lui donnez
- Vos comptes rendus d'interview (SharePoint, OneDrive, mails), anonymisés. Si vous n'en avez pas sous la main : le cas **StreamFlow** à télécharger.
- Votre workspace **Contexte**
- La fiche **solve-discovery** dans votre workspace **Expertise**

## Votre agent est un produit
- Petit d'abord : un agent qui fait bien l'étape **Sonder** vaut mieux qu'un agent qui survole les cinq.
- On itère : chaque nouvelle interview le met à l'épreuve, et vous l'améliorez.

## Les 45 minutes
| | |
|---|---|
| **5 min** | Le livrable : dessinez ce que l'agent doit rendre après une interview |
| **15 min** | Le workflow à la main : faites-le une fois dans une conversation, jusqu'à obtenir le bon livrable et les bonnes questions |
| **15 min** | L'agent : transformez ce qui a marché en instructions d'agent, relancez dans une nouvelle conversation |
| **10 min** | La version de lundi : corrigez une chose, une seule |

## Restitution, 2 minutes
Le livrable produit, la meilleure question posée par l'agent, ce que vous ferez ensuite.

## Pièges
- Une interview entière consomme beaucoup de quota : raccourcissez, ou faites résumer chaque interview d'abord, puis appliquez SOLVE sur les résumés.
- L'erreur n°1 : recopier la demande dans « problème réel ». Mettez-la dans les règles de l'agent.
